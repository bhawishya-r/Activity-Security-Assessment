# Botium Toys: Security Assessment

## Overview

A simulated security risk assessment of Botium Toys, a fictional company, completed as part of my cybersecurity learning journey.

The project focuses on reviewing security controls, identifying potential risks, evaluating compliance-related practices, and recommending improvements to the organization's security posture.

## Reports

- **Scope, Goals & Risk Assessment:** Defines the assessment scope, reviews assets, and documents the risk assessment.
- **Controls & Compliance Checklist:** Reviews security controls and compliance-related practices, with recommendations for improvement.

See the [`reports/`](reports/) directory for the full reports.

## Skills Practiced

- Security risk assessment
- Security controls review
- Risk identification and mitigation
- Compliance awareness
- Security documentation and recommendations

## Disclaimer

This is an educational simulation based on a fictional company and does not represent a real-world security audit or compliance assessment.
